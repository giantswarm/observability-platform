{{- if .Values.grafana.enabled }}
{{- if eq (dig "grafana" "service" "type" "" .Values.grafana) "NodePort" }}
Grafana listens on NodePort {{ .Values.grafana.grafana.service.nodePort }}. The kind config in doc/LOCAL_DEV.md maps it to localhost:3000.
{{- else }}
Open Grafana:

  kubectl port-forward -n {{ .Release.Namespace }} svc/grafana 3000:80
{{- end }}

Log in at http://localhost:3000 as `admin`. The password is in the `grafana` secret:

  kubectl get secret grafana -n {{ .Release.Namespace }} -o jsonpath='{.data.admin-password}' | base64 -d; echo
{{- if not .Values.observabilityOperator.enabled }}

Grafana has no datasources: the operator that provisions them is disabled. To add them, see
https://github.com/giantswarm/observability-platform/blob/main/doc/LOCAL_DEV.md
{{- end }}
{{- end }}
